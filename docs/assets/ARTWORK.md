# Product artwork

`icon.png` is the full-resolution illustrated app identity. `banner.png` is its matching panoramic repository/portfolio illustration. They depict original product mascots and conceptual interface elements; they are not captured private conversations or real usage reports.

The browser identity is a fox accountant in teal and amber. The desktop identity is an owl advisor in indigo and gold. Each icon is resized into native platform assets; the macOS build embeds a multi-resolution ICNS. Existing hero/social-card diagrams remain clearly synthetic explanations of the product interface.

Project artwork is distributed under the repository MIT license.
