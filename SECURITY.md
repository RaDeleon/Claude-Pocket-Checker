# Security

Please do not post credentials, private conversations or account exports in a public issue. Use GitHub private vulnerability reporting if enabled; otherwise use the contact route on https://angelodeleon.com to arrange a private report.

Describe affected versions, reproduction with synthetic data, impact and a suggested mitigation. These projects are experimental utilities, not an official Anthropic product. No response-time or support SLA is promised.

Only the published source and CI configuration are in scope for this repository. Claude and browser accounts remain under their respective providers' control.
